# IBM Data Engineer Training

This repository contains hands-on practice, labs, and notes from the **IBM Data Engineer Professional Certificate** program on Coursera.

---

## Structure

- **Linux and Shell/** — Cours, labs, and a complete mini-project on shell scripting and command-line tools.
- **Python/** — Python fundamentals for data engineering, including working with files, APIs, and data structures.
- **SQL/** — SQL queries, relational database design, and exercises.
- **NoSQL/** — Practice and examples using NoSQL databases.
- **ETL and ELT/** — ETL/ELT concepts, tools, and transformation logic.
- **Data Pipeline/** — Folder dedicated to building end-to-end data pipelines.
- **Data Warehouse Mart and Lake/** — Covers concepts and implementations of Data Warehouses, Data Marts, and Data Lakes.
- **Big Data/** — Concepts, tools, and hands-on labs with large-scale data.
- **Kafka/** — Exercises and examples using Apache Kafka for data streaming.
- **Spark/** — Training on Apache Spark for distributed data processing.

---

## Topics Covered

- Linux and Shell scripting
- Python for Data Engineering
- Relational databases and SQL
- ETL and ELT processes
- Data pipelines and orchestration
- Data Warehousing, Data Lakes, and Data Marts
- Big Data frameworks
- NoSQL databases
- Apache Kafka
- Apache Spark
- Cloud platforms (IBM Cloud, etc.)
